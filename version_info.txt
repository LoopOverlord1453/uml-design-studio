# Windows version resource for the packaged executable.
#
# WHY THIS FILE EXISTS
# --------------------
# The strings below are what Explorer shows under "Properties > Details" on
# the delivered UML-Design-Studio.exe. They are the one place where metadata
# travels with the binary, so they are kept under version control rather than
# generated at build time.
#
# Two rules are enforced by tools/test_regressions.py (section 19d):
#
#   * The text is ENGLISH and free of Turkish characters -- Explorer shows it
#     verbatim, so it has to read like the rest of the interface.
#   * FileVersion / ProductVersion must match TOOL_VERSION in
#     app/codegen/c_generator.py, so the version stamped into the generated
#     C/C++ headers and the version of the executable cannot drift apart.
#
# UML-Design-Studio.spec passes this file to PyInstaller on Windows only; on
# Linux and macOS it is skipped (a version resource is a Windows concept).

    ),
    kids=[
